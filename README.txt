SolarCleaner Pro - App Android (WebView)

1. Instala Android Studio.
2. File > Open > elige esta carpeta (SolarCleanerApp) y espera que sincronice.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. El APK queda en app/build/outputs/apk/debug/. Pasalo al celular e instalalo.
5. Conectate al WiFi SolarCleaner_PRO y abre la app: entra sola, sin escribir la IP.

Funciona con tu .ino tal como esta. Si cambias la IP, editala en MainActivity.java (URL).

CON GITHUB (sin Android Studio):
1. Sube todo el contenido de esta carpeta a un repositorio (incluida la carpeta .github).
2. Entra a la pestana Actions > Crear APK > espera que termine (verde).
3. Abajo, en Artifacts, descarga SolarCleanerPro-APK, descomprimelo e instala el .apk.
